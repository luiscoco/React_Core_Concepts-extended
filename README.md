# React Core Concepts Sample

This Vite + React project demonstrates many core React concepts with tiny, focused examples:

- JSX, components, props and state
- Lifting state up
- Controlled components (forms)
- useState, useEffect, useReducer
- Context and useContext
- Class components and componentDidMount
- React Router for navigation
- React.memo, useMemo, useCallback
- Refs and forwardRef
- Portals
- React.lazy and Suspense
- useLayoutEffect
- useImperativeHandle
- Error boundaries

## How to run

1. Install dependencies:

   npm install

2. Start the dev server:

   npm run dev

3. Open the URL shown in your terminal (usually http://localhost:5173).

Then click through the navigation links at the top to explore each concept.
